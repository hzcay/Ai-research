This project is a research assistant chatbot that helps users query and analyze academic papers. The main problem is that general LLMs like ChatGPT often hallucinate and cannot reliably reference specific content from research documents. I solve this by using a Retrieval-Augmented Generation (RAG) pipeline, where documents are chunked, embedded, and stored in a vector database.At query time, the system retrieves relevant chunks and feeds them into the LLM to generate grounded answers with citations.
